## 解消（2026-10-20 のループ）
| 課題 | 対応 |
|---|---|
| 新能力の演出が未確認 | 能力デッキで通し、回復・強化・吸血・召喚・命中の演出が出ることと JS エラーが無いことを確認 |
| チュートリアルが無い | 初回だけ、コイン説明→手札を場へドラッグ→相手へ攻撃の 3 段（指のガイド付き。初回は相手を「よわい」に） |
| 報酬・成長が無い | 対戦で点がたまり（勝ち 2・負け/引き分け 1）、2 点で宝箱=新カード 1 枚。最初は 16 枚。結果画面に獲得演出、デッキ画面に未獲得（鍵）の一覧。`?unlockall` で全開放（確認用） |
| CPU が呪文・回復・建築を使いこなせない | 回復・毒・強化の建築を CPU が評価するように。弱いカード（毒の祭壇・癒しの雨・戦の号令・バリケード）のコスト・数値を調整 |
| 相手デッキが固定 | テーマ別 6 種（商人・毒・巨人・連撃・狙撃・封印）を試合ごとに選ぶ |
| コスト 9〜10 が弱い | ドーン・ファイのクールタイムを 12・10 秒に。監査で 43〜46% |
| クールタイム台座が沈む | 台座を明るく、縁取りを濃い青に |
| 下段スタッツが HP バーに触れる | 場の上下に余白 |
| 効果音 C・D が A と同じ | 録音が少ない音は順に別の録音を当てる |
| PC 横長 | 縦型の盤面が仕様（クラロワの PC 版と同じ）。飾りの塔が左右にあるため据え置き |
| 開発サーバーの 404 | CLAUDE.md に「素材追加後は dev サーバー再起動」と記載 |
