## 残り
| 優先 | 区分 | 課題 | 方針 |
|---|---|---|---|
| 高 | 演出 | 新能力の演出（回復・強化・封印・交差斬り・貫通・吸血）が実際の戦闘で動くところを未確認 | 能力カードだけのデッキで通し、スクショと動画で確認 |
| 高 | 初心者 | チュートリアルが無い（遊びかたの文章だけ）。クラロワは最初の数戦で操作を教える | 初回だけ、手札→場→攻撃を指で示す 3 ステップ |
| 高 | 継続 | 報酬・成長が無い（全カード最初から解放、勝っても何も増えない） | 勝利でコイン（通貨）→宝箱→カード解放。カードを段階的に解放 |
| 中 | CPU | 呪文・回復・建築を使いこなせず勝率が低い（監査で 36〜45%） | 使いどころの評価を CPU に足す |
| 中 | CPU | 相手デッキが固定 1 つ（RIVAL）。毎回同じで飽きる | テーマ別の相手デッキを 4〜6 種、試合ごとにランダム |
| 中 | バランス | コスト 9〜10 の大型（ドーン・ファイ）が 41〜44% | コイン速度・能力付与・コストで調整 |
| 中 | 見た目 | クールタイムの青い台座が暗い絵の上で沈む | 縁を明るく／ChatGPT で作り直し |
| 中 | 見た目 | 自分の場の下段のスタッツが自分の HP バーに少し触れる | HP バーを少し下げるか場を上げる |
| 中 | 音 | 効果音の種類 C・D は、録音が 2 種類しかない音（倒れる・角笛）で A と同じ | ElevenLabs で追加 |
| 低 | 画面 | PC の横長では、盤面が細く手札のパネルが下端ぎりぎり | 横長用に左右へ余白の飾り、パネルの高さ調整 |
| 低 | 開発 | 開発サーバーで新しい素材が 404 になることがある（本番は問題なし） | 素材追加後は dev サーバーを再起動 |
