# autopilot バックログ（プロダクトバックログ）

プロダクトゴール: ドラクエライバルズ × クラロワの新感覚リアルタイムカードゲーム。画面・音・演出の質が 2 作に劣らず、戦略と PS が要り、中毒性がある。
並びは「価値 ÷ 手間」の目安。完了したら journal へ。旧メモは docs/backlog.md。

## 方針（ユーザー決定）
- PvP（オンライン対戦）は、ゲームとしての品質がユーザーの判断する水準に達してから導入する。それまではやらない。エモートも入れない。
- カード固有の演出は、コストが高いので要件から外す（共通演出の質を上げる）。
- **カードのレベル機能は作らない**（ライバルズに合わせる。成長はカードの解放とトロフィー・アリーナで）。
- 素材（絵・音）はユーザー用意か、ダウンロードが通る方法がある時のみ。

## 参考画面の実測の進め方（試行メモ 2026-10-24）
- ブラウザで YouTube を開き、`video.currentTime` で位置を指定して静止、`canvas.drawImage(video)` で画素を読める（汚染されない）。ズームのスクリーンショットも可。
- 試した動画（ハネハネのバランス調整動画）は 854×480 で、ゲーム画面が横 273px しかなく実測には粗すぎた。**画面いっぱいの高解像度のプレイ動画**（実況なし）が要る。`#movie_player.setPlaybackQualityRange('hd1080')` で画質を上げられる。
- 検索結果ページの取得はこのペインで安定しなかった（要素が出ない）。動画 URL を直接指定するのが確実。ユーザーに URL かスクリーンショットをもらうのが最短。

## 保留（ユーザー決定待ち）
- 参考画面との実測比較: 視聴ページは開くと音が出る（ユーザーから音を出さないよう指示あり）、埋め込みはエラー 153 で再生不可、サムネイルは小さく加工されていて測れない。**ユーザーにクラロワ／ライバルズのスクリーンショットをもらえれば、そこから数値を測る**。
- PvP（品質到達後）。カード固有の演出（コスト高のため外す）。
