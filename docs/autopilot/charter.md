# 自走改善の憲章

ユーザーの指示が無くても、リアルカードバトルの品質を上げ続けるための取り決め。次の実行はここから読み始める。

## 最上位のゴール（2026-10-24 ユーザー指示「ループを回してブラッシュアップ」）

遊んで楽しく、クラロワ／ドラクエライバルズと同じ水準に見えて触れること。
騙す・煽る・不利益を隠す設計（ダークパターン）は使わない。

## 守る核

`src/game/` のゲーム性（クールタイム制の攻撃・割り込み・上書き・予約）。壊さない。

## 許可

- 変更してよい範囲: UI・演出・操作性・カードバランス・CPU。ルールの根幹は変えない。
- 公開: `npm run deploy` を修正のたびに。
- 条件: 変更前に `git tag autopilot/<連番>-<名前>`。ルール数値を変えたら `npm run simulate` / `npm run audit` で前後を測り journal に書く。
- 相談が要るもの: 課金、外部サービスへの送信、音の差し替え（音は録音のみ）。

## 並列と分担

- 既定 sonnet、並列は 2 件まで。コードを書かせるときは `isolation: worktree`。
- ブラウザは URL に `?mute`。playwright は待ちに必ず timeout。

## 測定の道具

| 目的 | コマンド |
|---|---|
| テスト | `npm test` / `npm run typecheck` |
| 勝率・試合時間 | `npm run simulate` |
| カード別勝率 | `npm run audit` |

## 止める条件

- 同じ領域で 3 回続けて改善なし → その領域を止める。
- 公開版が壊れたら最優先でタグへ戻す。
