# 仕様

クラロワ × デュエルマスターズ。リアルタイムで進むカードバトル。
シールド・タップは無し（ドラクエライバルズ基準）。

## 勝ち負け

- 相手プレイヤーの HP を 0 にしたら勝ち。プレイヤーの HP は **20**。
- 試合は **3 分**。最後の 1 分はコインが 2 倍速でたまる。
- 時間切れのときは HP の多い方が勝ち。同じなら引き分け。

## コイン

- 時間で自動的にたまる。**4 秒で 1 枚、上限 10 枚**（最後の 1 分は 2 倍速）。開始時は 5 枚。
- コインは **召喚（呪文を使うのも含む）にだけ** 使う。攻撃にはコインを使わない。

## デッキと手札

- デッキは 10 枚。手札 4 枚と「次のカード」1 枚を見せる。
- 使ったカードはその場でデッキの一番下へ戻り、次のカードが手札に入る（クラロワ方式）。
- 最初は 10 枚固定（自分と CPU で別のデッキ。デッキ編集は後で）。

## カードの種類

| 種類 | 場に出るか | 数字 | できること |
|---|---|---|---|
| ユニット | 出る（1 枠） | 左上 召喚コスト・右上 クールタイム（秒）・左下 攻撃力（赤）・右下 HP（緑） | 攻撃する |
| 建築物 | 出る（1 枠） | 左上 召喚コスト・右下 HP（緑） | 攻撃しない。場にあるだけで能力が効く。攻撃される |
| 呪文 | 出ない | 左上 召喚コスト | 使ったらすぐ効いて、デッキの下へ戻る |

- 値と能力はカードごとに固定。カード表は `src/game/cards.ts`（説明文は `abilityLines`）。

## 場と攻撃

- 自分の場は **3 枠**（`rules.ts` の `FIELD_SLOTS`）。手札のユニット・建築物を場へドラッグして召喚する。
  自分のカードがいる枠に重ねて召喚すると、元のカードを除いて置き換える（倒れたのではないので死亡時は起きない）。
- 場のユニットを相手のカードか相手プレイヤーへドラッグして攻撃する。
- **攻撃の制限はクールタイムだけ**。クールタイムは **カードごとの値**（`cards.ts` の `cd`、10〜22 秒ほど）で、
  攻撃したあと・召喚したあと、その秒数は攻撃できない（速攻は召喚直後だけ待たない）。
- **溜め**: 攻撃・呪文・召喚時の狙撃や足止は、選んでから **1 秒**（`rules.ts` の `WINDUP_MS`）たって効く。
  その間は攻撃元から対象へ矢印と照準を出す（CPU の行動も見える）。溜めの間に攻撃元か対象が場から消えたら中断。
  クールタイムとコインは選んだ時点で使う（中断しても戻らない）。範囲の呪文は対象が消えないので必ず効く。
- 溜め中の攻撃は、当たる瞬間に対象を狙えなくなっていたら（倒れた・ブロッカーが出た・壁ができた）中断する。
- **ターゲット**: ユニットを敵へドラッグすると、その対象がターゲットになる（青い点線の矢印が残る）。
  クールタイム中なら明けた瞬間に、そのあとも明けるたびに、同じ対象への攻撃（溜め）を自動で始める。
  対象を狙えなくなったら（倒れた・ブロッカーが出た・壁ができた）その時点で外れる。
  どこにも当てずに離すと外れ、別の対象へドラッグし直すと置き換わる。
- カード同士の戦闘は **お互いにダメージ**（ライバルズ方式）。攻撃した側も相手の攻撃力ぶん HP が減る。
  建築物は攻撃力が 0 なので反撃しない。
- **プレイヤーの攻撃力は今は 0**（`rules.ts` の `PLAYER_ATK`。0 なので反撃しない。値を戻せば、攻撃してきたユニットに反撃する・遠隔は受けない）。
  HP の横に赤い四角で出す。
- HP が 0 になったカードは場から消える。減った HP は戻らない。
- 「ブロッカー」: 相手の場にブロッカーがいるときは、ブロッカーしか攻撃対象に選べない。
- **状態アイコン**: 場のカードの上端に、いまの状態（ブロッカー・結界・ステルス・遅延中）を丸いアイコンで出す。
  手札とデッキ画面には出さない（能力は説明で見る）。
- **壁**: 場が 3 枚うまっている間、そのプレイヤーは攻撃されない（カードは攻撃できる）。
  能力によるダメージ（遺言など）は壁を通る。

## 能力

説明文はドラクエライバルズ式（「召喚時：」「攻撃時：」「死亡時：」「N 秒ごと：」）。カードの面には書かず、長押しとデッキ画面で見る。

| 名前 | 効果 |
|---|---|
| 速攻 | 召喚してすぐ攻撃できる |
| 奇襲 | プレイヤーへのダメージ +N |
| 討伐 | 攻撃時：敵カードへのダメージ +N（反撃には乗らない） |
| 鉄壁 | 受けるダメージ -N |
| 結界 | 最初に受けるダメージを 0 にする |
| ステルス | 自分で攻撃するまで、攻撃・狙撃・足止・単体の呪文・砲撃の対象にならない。全体攻撃には当たる。場の枚数（壁）に数えない |
| 遠隔 | 自分から攻撃したときは反撃を受けない |
| 攻撃時（ヴァルガ） | 狙った相手のほかの敵カード全員に 1 ダメージ |
| 鼓舞 | ほかの味方の攻撃力 +N |
| 増収 | 場にある間、コインのたまる速さ +N% |
| 祈り | 場にある間、味方ユニットのクールタイム -N%（最短 40%） |
| 仲間 | 召喚時、空き枠に志願兵（攻撃 1・HP 1）を出す |
| 修復 | 召喚時、自分の HP を回復 |
| 狙撃 | 相手のカードの上へドラッグして召喚すると、そのカードに固定ダメージ |
| 足止 | 相手のカードの上へドラッグして召喚すると、そのカードは数秒攻撃できない |
| 遺言 | 倒れたとき、相手のプレイヤーにダメージ |
| 生産 | （建築物）数秒ごとに空き枠へ志願兵を出す |
| 砲撃 | （建築物）数秒ごとに相手のいちばん HP の低いカードにダメージ |
| 単体 | （呪文）相手のカードの上で使うと、そのカードにダメージ |
| 全体 | （呪文）相手のカード全員にダメージ |
| 遅延 | （呪文）相手のユニット全員のクールタイム +N 秒 |
| 再動 | （呪文）味方ユニット全員のクールタイムをなくす |

## 操作

- カードはドラッグで使う（タップでは使わない）。長押しで説明（説明を見ている間は止まる）。
- 呪文: 単体は相手のカードの上で離す。それ以外は盤面のどこかで離す。
- ドラッグ中は狙える対象だけを光らせ、狙えない対象は暗くする。

## 相手

- まず CPU 戦だけ。オンライン対戦は後で。

## 画面（スマホ縦持ち）

**対戦中は画面全体が盤面**（クラロワと同じ）。戻る・設定・? のボタンは置かない
（全アプリ共通のヘッダーの決まりの、このアプリだけの例外。ユーザー指定）。抜けるのは決着後だけ。

```

     相手の場（3 枠）
```

## バランスの基準（2026-10 改訂）

- 能力なしのユニット: スタッツ合計（攻撃＋HP）≒ **コスト×2+1**。能力をつけたら、その分スタッツを減らす。
- 登場時に敵を選ぶカード（リオ=狙撃、シオ=足止め、ネロ=破壊）は、**場に置いたあと、効かせる敵カードをタップして選ぶ**。
  選べる敵がいて選ばなければ配置失敗（コスト・手札は変わらない）。選べる敵がいなければ、そのまま置ける。
  足止め・破壊は敵ユニットだけ。ステルス中の敵は選べない。選んだあとは溜め（1 秒）を経て効く。
- 攻撃が中断されたとき、クールタイムは選ぶ前に戻る（やり直しにならない）。
- 新能力: 破壊（結界・軽減を無視して倒す）／号令（自分のほかのユニットのクールタイムを減らす）／全破壊（建築物以外のほかのユニットを敵味方とも破壊）。
- コスト 6 以上（コスト/クールタイム/攻撃/HP）: ダリウス 6/15/7/7、ネロ 7/20/4/8（破壊）、ルナ 8/10/8/8（号令 10 秒）、グラム 9/15/7/10（ブロッカー）、オルガ 10/30/10/10（全破壊）。

- **召喚直後のクールタイムは半分**（速攻は 0）。2 回目の攻撃からは、そのカードのクールタイム全体。
- 2026-10 調整: アリア 3/3、ガストン 2/3。

## 追加カード 40 種（2026-10）

- **基礎スタッツ（能力なし）**: コスト 1〜5 は攻撃・HP がコストと同じでどちらかが +1（recruit / footman / lancer / knight / captain）。コスト 6 以上は攻撃・HP ともコスト+1（warlord 7、champion 8、ogre 9、dragoon 10）。
- **新しい能力**: 狙い撃ち（ブロッカー・壁を無視して攻撃）、2回攻撃（1回のクールタイムで2回動ける）、攻撃不能（bulwark）、吸血、不屈（致死ダメージを 1 度だけ HP1 で耐える）、猛毒（攻撃した相手に毒）。
- **登場時**: 味方を選んで回復／強化、味方全体の強化、相手を毒・封印・攻撃不能（10 秒）にする。**死亡時**: 味方全体強化、相手全体に毒。
- **建築物**: 診療所（味方回復）、毒の祭壇（相手に毒）、鍛冶場（味方の攻撃+1）。**呪文**: 癒しの雨、戦の号令、毒霧、封印の儀。
- **状態**: 毒 = 攻撃時に毒の値だけ自分がダメージ／封印 = 能力を無効／攻撃不能 = 一定時間攻撃できない。状態は盤面のアイコンで見える。
- 詳細な数値は `src/game/cards.ts`、挙動の確認は `__tests__/abilities2.test.ts`。

## 成長・初回案内・相手デッキ（2026-10）

- **成長**: 最初に持つカードは `START_CARDS`（16 枚）。対戦の終わりにポイントが入り（勝ち 2・負け/引き分け 1）、2 点で宝箱が開いて持っていないカードが 1 枚増える。安いカードが出やすい重み。保存は localStorage。`?unlockall` で全開放。実装は `src/storage/collection.ts`。
- **初回案内**: 初めての対戦だけ、コイン→召喚→攻撃の順に案内（`src/ui/Tutorial.tsx`）。初回は相手を「よわい」にする。
- **相手デッキ**: `RIVAL_DECKS`（6 種）から試合ごとに 1 つ選ぶ。

## 割り込み・上書き（このゲーム特有のギミック）

- **割り込み**: 攻撃は溜め（1 秒）の間、いつでも中断できる。相手の場にブロッカーが出る（または壁が完成する・対象が倒れる）と、溜め中の攻撃はその場で中断し、クールタイムは選ぶ前に戻る。ブロッカーの能力「割り込み時：…」が攻撃元に効く（ダメージ・足止め・コイン）。
- **攻撃中断時**の能力: 自分の攻撃が中断されたとき起きる（クールタイムなし・強化）。
- **上書き**: 自分のカードの上に召喚すると入れ替わる。入れ替わったカードの「**生贄時**」の能力が起きる（コイン・ダメージ・回復・上書きしたカードの強化）。新しいカードの「**上書き召喚時**」の能力（強化・コイン返却）も起きる。上書きされたカードを狙っていた攻撃は「かわされた」（空振り）。
- **パリィ**（呪文）: 溜めなしですぐ効き、相手の溜め中の攻撃をすべて中断させて攻撃元を足止めする（溜め中の攻撃が無いと使えない）。
- 演出: 「割り込み！」「かわされた！」「生贄！」「パリィ！」の大きな文字、衝突・断ち切り・上書きの光（ChatGPT 製の素材）、入れ替わったカードの残像、相手の溜め中の線の真ん中に「！」の警告。
- 新カード 13 枚: ヴィゴ・ミーア・ザック・ドミニク（割り込み）、ボルク・ジーナ（攻撃中断）、ユラ・ガイ・リーゼ・フェン（生贄）、クロウ・レグ（上書き召喚）、パリィ（呪文）。

- **討伐時**: 自分の攻撃で敵ユニットを倒したとき（反撃・毒では起きない）。ロッコ（コイン +2）、グリム（自分が +1/+1）。ほか追加: ピエロ・ロデリク・セドリック・ヴェラ。
